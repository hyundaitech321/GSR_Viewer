GSR Viewer

Read .GSR scan-tool recordings in your browser. Files are read on your device and never uploaded.

Drop a .GSR, .GSRZ or .MSR file here

Drop two recordings to compare them, for example a customer's car against a known-good one. Channels are matched by name and drawn on the same lane.

Or use “Try example data” to see how it works.

How values are read
  • Each channel's scale, offset, unit and signedness come from the recording's own channel table, so numbers match what the original viewer shows.
  • Left-click sets cursor 1 and right-click sets cursor 2, as in the original viewer. Drag with either button to adjust, or press 1 or 2 and use the arrow keys. On a touch screen, use Add cursor 2 and then tap. The reading is exact in samples; it is in seconds only as far as the seconds-per-sample box is right.
  • The time between samples is not stored in a form this viewer can read yet. It assumes the value above (default 1 s). Change it and the time axis follows.
  • Status channels show the state number the original program plots. Click a state in the Values tab to name it; names are remembered in this browser only. A few names confirmed on a real recording are built in.
  • Channels the recording marks as raw status words show their raw number.
  • Temperatures, speeds and pressures are stored in metric (°C, km/h, hPa) even when labeled °F, MPH or psi. The checkbox converts them to the labeled unit; turn it off to see the stored values. This is inferred from the data, so check a channel or two against the original viewer.
